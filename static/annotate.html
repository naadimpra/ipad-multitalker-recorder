Shortcuts

While typing

Enter / Shift+Enter
Next / previous segment, and play it
Esc
Pause, or play this segment again (resumes a little before where it stopped)
Shift+Esc
Play this segment from its start
Tab
Next line (漢字 → よみ → 高低 → romaji)

On the pitch line (高低)

L H D
Low / high / devoiced for this mora, then on to the next
← →
Previous / next mora (↑ high, ↓ low)
Click a box
Change it: L → H → D
＊ in the よみ
Same as D: し＊ is devoiced, written shI in the romaji

Outside a text box

Space
Play / pause
← →
Back / forward 2 s (with Shift: 0.5 s)
↑ ↓
Previous / next segment
Enter
Type in the selected segment
S
Split the selected segment at the playhead
M
Merge it with the next one of the same speaker
1 … 8
Set its emotion: Neutral, Happy, Sad, … in the order of the list in each row
Delete
Delete the selected segment
⌘/Ctrl+Z
Undo
+ −
Zoom

On the waveform

Click
Move the playhead; click a segment to select it
Drag on empty space
Mark a new segment
Drag a segment edge
Adjust where it starts or ends
Double-click a segment
Play it and type
